# equipe-labs/homebrew-tap

Homebrew formulae for [equipe](https://github.com/equipe-labs/equipe) — a full
software squad of AI agents, on your own Claude Code and Codex plans.

```bash
brew install equipe-labs/tap/equipe
```

Update with `brew upgrade equipe`.

`Formula/equipe.rb` is written by equipe's release workflow on every release;
don't edit it by hand.
